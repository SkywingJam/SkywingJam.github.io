## 场景与动效

`wave-scene.js` 创建有厚度的连续网格，以三组低频波实现位移，并通过同一函数的解析偏导更新法线。玻璃使用物理透射材质；程序化 HDR 灯带环境经过 PMREM 预过滤，背景在场景内部参与折射。HTML 内容位于独立前景层。

最终材质起点：`transmission=1`、`roughness=0.035`、`ior=1.47`、`thickness=0.38`；模型尺寸 32 × 0.16 × 40。相较最初方案，网格向远处延伸，以避免近处露出水平截断边；桌面分段 160 × 144，窄屏初始化使用 80 × 80。未使用 Bloom 或额外后处理。

- 波面缓慢移动，曝光有很小的呼吸变化；鼠标仅在首屏产生平滑的镜头偏移。
- 可暂停 / 恢复；暂停后时间停止累计，主题仍可切换。
- 首屏离开视口、页面隐藏时取消动画帧；返回后重新开始计时，不追赶后台时间。
- 内容入场只发生一次，链接与箭头提供轻微反馈，键盘 focus 明确可见。
- 减少动态效果时使用静帧、显示全部内容并关闭平滑滚动；偏好变化可即时应用。
- DPR 上限为桌面 1.5、窄屏 1；窄屏目标 30fps。持续帧时长超预算时依次降低分辨率，仍不足则使用静帧。本版通过分辨率降级控制成本，尚未加入单独的低复杂度材质档位。

静态 poster 从本场景导出，亮色约 **21KB**、暗色约 **48KB**（十进制），用于加载前、无 JS、减少动态效果、无 WebGL2、模块加载失败和上下文丢失的回退。程序化环境不需要额外 HDR 下载。Three.js 模块原始体积合计约 **720KB**，发布服务器的压缩效果需在部署后检查。

## 本地验证

浏览器：Codex 内置浏览器。本次响应式测试使用桌面浏览器视口模拟，不等同于手机实机或多个浏览器引擎验证。

| 检查 | 结果 / 边界 |
| --- | --- |
| JavaScript 语法 | `node --check lab/lab.js` 与 `node --check lab/wave-scene.js` 通过 |
| HTML 资源与锚点 | 检查 14 个 ID、25 个资源/链接引用，无重复 ID 或缺失本地引用 |
| 路由 | 本地输入 `/lab` 自动规范化到 `/lab/`，返回 200；直接 `/lab/` 返回 200 |
| 资源 | 两套 poster、两个 Three.js 模块均返回 200 |
| 响应式 | 1440、1024、760、700、390、375、320px 视口均无页面横向溢出 |
| 视觉 | 检查首屏、两个实验条目、兴趣、笔记、页尾；检查亮/暗主题与手机布局 |
| 主题与首页入口 | 键盘 Enter 切换主题；从 Lab 返回首页再通过 Lab 链接进入，主题一致 |
| 暂停 | 点击后进入 `paused`，按钮变为 Resume motion；恢复后继续运行 |
| 首屏生命周期 | 滚动到 About 后进入 `idle`，停止动画调度 |
| reduced-motion 逻辑 | 临时测试页模拟 MediaQueryList 的变化事件；切换后进入静态状态、隐藏动效控件、全部入场内容可见；恢复后重新运行。真实系统设置切换及 CSS 媒体查询实机效果尚未验证 |
| WebGL2 不可用 | 临时测试页阻止 WebGL2 上下文创建，保留 poster 与页面内容 |
| 上下文丢失 | 通过 `WEBGL_lose_context` 触发，回退静帧并隐藏动效控件，无新增控制台错误 |
| 无 JS | 去除全部脚本的临时静态副本，内容和 poster 可见，没有隐藏入场条目 |
| 帧时长 | 本地桌面 1440 × 1000 采样中位约 20ms；仅描述此测试环境，不能推导手机性能 |

测试与静帧导出使用的临时 HTML 未包含在正式页面中。自动质量降级各档位、长时间运行、后台切换、BFCache、模块网络失败及被阻止的 localStorage 仍应在完整发布检查中覆盖。尚未测量发布环境的 LCP、CLS、INP；未测试真实 iOS Safari、Android Chrome 或 Firefox。

## 预览与维护

从仓库根目录运行：

```sh
python3 server.py
```

打开 `http://localhost:8001/lab/`。不需要 npm 安装或打包。

内容直接编辑 `lab/index.html`：

1. 新实验沿用 `.experiment` 结构，添加唯一 ID、标题、描述、真实状态、图片或视觉、可用的演示/源码链接。
2. 兴趣区域目前描述两个已实现实验的探索方向；收集真实兴趣资料后可以替换或增加条目。
3. 在 Field notes 中使用 `<time datetime="YYYY-MM-DD">` 记录真实更新。
4. 布局与配色在 `lab/lab.css`；页面交互在 `lab/lab.js`；波形与材质在 `lab/wave-scene.js`。
5. 修改场景构图后重新导出两套 poster；更新 Three.js 时保持两个模块同版本，检查注入 shader chunk 的兼容性并保留许可证。

未来加入第三个项目或真实兴趣时优先更新内容，现有结构无需引入 CMS、搜索后端或框架。
