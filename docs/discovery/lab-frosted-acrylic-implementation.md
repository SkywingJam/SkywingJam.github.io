## 实现

`/lab/` 使用 Canvas 2D 分层合成，保留 `7e3038a` 的横向长波、正弦叠加、温和倾斜与滚动展开。没有回退主站首页，也不再加载 Three.js。材质是二维的光照与透射近似，不是真实三维体积折射。

- 日光：暖象牙背景、暖白局部反射、灰蓝层间阴影。进一步降低环境填充与大范围泛白，把主光集中在左上方；增强曲面朝向对亮度的影响，提高迎光面反射与背光侧阴影的差异，强调光照在材质上的感觉。
- 月光：深蓝 `#081326` 至 `#132844` 环境、银蓝细边和较弱的表面反射。与亮色共用几何、相位和纹理，切换只插值配色。
- 材质：先画后景与投影，再通过波面裁切合成柔化后景；曲线斜率影响局部亮度，细边与局部反射最后绘制。页面文字独立于画布。
- 霜面：半分辨率离屏缓冲区；支持 Canvas filter 时对透射图像做 5–8px 柔化，不支持时用多点偏移采样。首轮低分辨率放大在大屏产生阶梯感，已替换；曲线采样从 12px 加密到 6px，修正渐变方向与分段重叠，并移除宽屏无必要的画布扩张。
- 纹理：固定种子的细颗粒缓存复用，避免随机闪烁。
- UI：收敛主标题尺寸，首屏改用简洁无衬线字形；精选条目减轻为顶部细线和低透明度背景。实验、兴趣、笔记与个人介绍结构保留。

### 根据反馈调整独立运动

三层不再共享同一推进相位。每层具有独立初相位、波长、速度、方向、呼吸周期及谐波演进。

| 层 | 初相位 | 基础空间频率 | 相位速度（rad/s） | 呼吸频率（rad/s） |
| --- | --- | --- | --- | --- |
| 后层 | 0.68 | 1.14 | +0.073 | 0.23 |
| 中层 | 2.05 | 0.93 | −0.051 | 0.31 |
| 前层 | 2.48 | 1.27 | +0.089 | 0.19 |

以 delta time 推进；相位不在 resize 或主题切换时重置。根据最终交叠反馈，移除相邻波层的最小间距约束，避免后一层被前层挤出折角。各层几何完全独立，允许相交；按后到前绘制，交叠区域裁切并柔化已绘制的后景，加上当前层的霜面、阴影和高光，表现正常的亚克力覆盖与透射。滚动展开与鼠标倾斜均有上限；移动端关闭指针倾斜。

### 生命周期与成本

保留暂停 / 恢复、首屏离屏休眠、页面隐藏停止调度、reduced-motion 静帧、无 Canvas / 模块失败降级及 BFCache 恢复处理。暂停时允许主题过渡，波形时间保持不变。

桌面 DPR 上限 1.5，窄屏上限 1；窄屏按约 30fps 调度。连续绘制提交耗时过高时依次降低缓冲区 / DPR、减少波层，最终回退 poster。这个指标不包含全部异步 GPU 工作，不能当作完整能耗或帧率测量。

从同一渲染器固定相位导出两套 WebP poster：日光约 23.0KB，月光约 25.0KB。新波面模块约 14.7KB；正式 Lab 的两个 JS 文件合计约 19.3KB。首版约 720KB 的 Three.js 依赖仅保留于 archive，当前页面不会请求它们。以上为未压缩文件大小，非部署后的实际传输量。

## 预览与重复检查

从根目录运行 `python3 server.py`，访问 `http://localhost:8001/lab/`。静态站点无需安装或打包。

可选的浏览器回归脚本 `scripts/check-lab.cjs` 依赖 Playwright；可使用已有安装。先启动本地服务器，再执行：

```sh
node scripts/check-lab.cjs
# 材质调整后重新生成同相位亮暗 poster：
node scripts/check-lab.cjs --update-posters
```

默认使用 Playwright Chromium；可通过 `BROWSER_EXECUTABLE` 指定已安装的 Chromium 浏览器，通过 `PLAYWRIGHT_MODULE` 指向已有 Playwright 包。`LAB_BASE_URL` 默认 `http://127.0.0.1:8001`，`LAB_QA_OUTPUT` 默认系统临时目录下 `lab-qa`。普通检查不会修改正式资源，只有 `--update-posters` 写入 `lab/assets/`。
