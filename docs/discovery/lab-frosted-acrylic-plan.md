# /lab 修改方案：日光与月光下的霜面亚克力

日期：2026-10-03（Australia/Melbourne）  
分支：`discovery`  
状态：**已于 2026-10-03 获得后续执行授权并完成本地实现。** 详见 [实现与验证记录](lab-frosted-acrylic-implementation.md)。以下保留原始设计决策与当时范围。

## 方向判断

采用 `7e3038a` 的横向分层波面作为形态与运动基础，增强受光、局部高光、层间阴影和霜面透射。亮色呈现日光穿过亚克力的暖亮感；暗色呈现深蓝环境中的冷月光。这个方向可行，也更贴近用户希望保留的旧版波形。

目标是「能看出厚度的半透明磨砂亚克力」：内部柔和散射，边缘仍有精细亮线，前后波层透过材质变得模糊。霜面强度要有节制，避免整体变成乳白色塑料、发光线条或不透明波浪。

本方案作为下一轮首选方向，替代此前优先用视频背景的建议。视频仍是材质原型不达标时的备选；本次不生成视频，也不开始替换当前 Three.js 版本。

## 已核对的参考实现

参考仓库：`SkywingJam/SkywingJam.github.io`。完整提交：`7e3038a3ae26ee5363ba6830f8dc64e326e38dbd`。

[该提交的 index.html](https://github.com/SkywingJam/SkywingJam.github.io/blob/7e3038a3ae26ee5363ba6830f8dc64e326e38dbd/index.html)

已通过 GitHub 连接器读取波面绘制部分，并检查本地提交的动画、主题与 resize 逻辑。该提交本身的改动是 capability 分隔线；这里参照的是它对应的完整页面快照。

当前参考快照采用 **Canvas 2D**：

- 四层波面，叠加三组正弦形变，用二次曲线连接采样点。
- 从波峰向屏幕底部封闭填充，以纵向渐变表现表面。
- 固定 4px 高光描边，`shadowBlur=15`、`shadowOffsetY=10` 表现亮边与阴影。
- 鼠标影响倾斜，滚动影响波层间距，动画包含缓慢起伏。
- 初始化含随机参数；resize 重建波形；时间推进、阻尼按帧计算；DPR 未限制。

它有适合本次方向的轮廓与层次组织，但没有真实体积折射或光照模型。增强版首先做 **Canvas 2D 的分层材质近似**；达到效果再决定是否需要更复杂的渲染方式，不承诺只增加 blur 就能得到真实磨砂透射。

## 视觉规范

| 项目 | 日光 / 亮色 | 月光 / 暗色 |
| --- | --- | --- |
| 背景 | 暖象牙白 `#F2EEE5`，局部柔和日光晕 | 深海军蓝 `#081326`，向 `#132844` 轻微渐变 |
| 主光 | 左上方宽而柔和的暖白光 | 同方向、较窄的冷银蓝光，整体亮度更低 |
| 表面 | 中性透明基底，暖光沿曲率扩散 | 带少量蓝色透射，暗部仍能分辨波层 |
| 边缘 | 局部白亮点 + 连续但不均匀的细亮边 | 克制的银蓝亮边，避免电蓝霓虹与金属感 |
| 阴影 | 低饱和灰蓝或灰褐，柔和层间遮挡 | 深蓝阴影，避免纯黑把层次压没 |
| 霜面 | 透过表面的后景柔化，内部有轻微乳化 | 同一材质结构，在较低环境亮度下保留柔和透光 |
| 文字 | 深墨色，避开主高光 | 偏冷的柔白，避开强亮边 |

颜色是艺术调参起点，最终以原型、文字对比度和不同显示尺寸为准。日光/月光由页面主题选择，不自动根据时间改变，也不需要在画面中放太阳或月亮图案。

保持三到四层横向长波面，前、中、后层具有明确重叠关系。沿用 `7e3038a` 的长波轮廓和慢速运动，减少容易形成团状封闭区域的交叉起伏。近层略清晰且厚，远层更柔、更低对比度。

## 拟实施的渲染结构

### 1. 波形与运动基础

从参考快照提取波形模块，保留横向层叠和温和的鼠标倾斜。用固定种子或确定性配置保存层间相位，resize 仅重算尺寸；将相位和阻尼改成基于 delta time，避免刷新率改变速度。

滚动展开效果仅保留有限幅度，不让层间结构持续被滚动方向累积改变。倾斜与呼吸必须受限。后续实现根据用户反馈允许独立波层自然交叠，不通过层间距约束修改几何；交点处采用亚克力覆盖与霜面透射，不出现挤压折角。

### 2. 方向光与表面明暗

为整幅画面设一个稳定主光方向。根据二维曲线的斜率构造近似朝向，结合光源位置调整明暗；这是一种美术近似，不是完整三维法线光照。

将当前单一纵向渐变拆成受光区域、主体色和背光区域。大面积柔光建立体积，局部亮点强调曲率，避免每条脊线从左到右同样亮。

### 3. 高光与厚度

高光分为宽而弱的柔光晕、窄而清晰的边缘反射，以及少量局部增强的亮段。随曲率与入射方向连续变化，不额外添加随机闪烁。

用轻微偏移的背缘、厚度渐变和重叠区域的颜色变化表现亚克力边界。避免把两条平行白线画成管状边缘，也不要让四层波面都出现同等强度的粗描边。

### 4. 阴影与层间遮挡

按后到前的顺序合成。前层对后层产生柔和的偏移阴影，方向与主光一致；层距较近处阴影更集中，远处更软、更淡。

将阴影限制在后层或接近重叠的区域，避免波峰外缘出现贯穿画面的黑色描边。阴影为表现层次的近似，不实现完整透明体阴影或真实焦散。

### 5. 霜面透射

把已经绘制的后景作为离屏图像，在前景波面内部裁切后，合成经过柔化的后景，再叠加薄雾色和极弱的静态颗粒。霜面模糊主要影响「透过材质看到的内容」，表面轮廓和近景亮边仍保持清晰。

先尝试局部多分辨率图像合成：后景在小尺寸离屏画布中缩小，再放大采样形成柔化；需要时混合几个偏移采样，按效果与成本取舍。不要每层重新抓取整个网页，也不要把 HTML 文字一起模糊。

`CanvasRenderingContext2D.filter` 可作为能力检测后的增强路径，不作为唯一依赖；MDN 标注该属性兼容性仍有限。[Canvas filter 文档](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter)

Canvas 2D 不能直接折射画布外的 HTML。需要被霜面柔化的光场和后层波面应在同一合成体系内；界面始终独立叠在上方。静态噪声纹理缓存复用，避免逐帧重新生成颗粒。

## 页面与交互安排

适用范围为 `/lab/`。此次参考 `7e3038a` 的波面及运动，不要求整站退回该提交，也不照搬全部旧版组件样式。

- 首屏以横向波面为主体，主标题适度收敛，增加编号、细线和紧凑元数据；精选信息块减轻边框和实心底色。
- 保留现有实验、兴趣、笔记的内容结构；后续填充真实内容。
- 亮暗主题共用几何、相位和随机种子，只平滑切换光色、背景和阴影；切换不重建波形。
- 保留暂停、减少动态效果、首屏离屏休眠及页面隐藏时停止调度。
- 移动端取消鼠标倾斜，优先减少合成分辨率和波层数量。

## 性能与降级

Canvas 2D 的依赖体积可以较小，但多层模糊与合成仍可能昂贵，不能仅凭技术名称认定比当前 3D 省电。

原型预算：桌面 DPR 上限 1.5，移动端上限 1；先从三个波层、半分辨率霜面缓冲区开始，目标桌面 60fps、移动端 30fps。只有在材质和运行预算允许时才增加第四层或提高缓冲区分辨率。以上为目标，尚无测量结果。

尽量复用画布、渐变或纹理资源；每帧只重绘发生变化的合成内容。连续超预算时先降低霜面缓冲区分辨率，再减少波层，最终回退静态 poster。亮/暗 poster 在材质定稿后重新导出。

## 后续执行顺序与验收

1. 在隔离原型中复现旧版波形，先校准轮廓、镜头构图和前后层次。
2. 固定一个静态相位，完成日光版的主体渐变、高光、阴影与霜面，再用同一相位制作月光版。
3. 材质成立后加入慢速运动、呼吸、鼠标倾斜和主题过渡，验证随时间变化时层次仍稳定。
4. 对照当前 Three.js 首版测试画质、下载量、帧时长与真实设备运行表现。若 Canvas 2D 原型无法清楚表达霜面透射，保留该视觉与波形设计，再评估轻量 shader 合成或同源预渲染视频。
5. 原型达标后再实现正式 `/lab/`，执行 archive 迁移、更新链接和补齐验证记录。

验收重点：日光版有温暖通透感；月光版背景明显为深蓝且暗部可读；霜面内部柔和、轮廓清晰；同一画面能辨认至少三个前后层次；没有整屏泛白、金属铬感、霓虹描边或随机闪烁；文字不被模糊，高光经过时仍可阅读；暂停、主题切换、resize 和减少动态效果均不造成跳变。
