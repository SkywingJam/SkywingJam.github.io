# /lab 视觉、交互与动效打磨

日期：2026-10-03（Australia/Melbourne），分支 `discovery-light-study-reuse`。

所有新增动效都是装饰性的：系统“减少动态效果”与页面暂停按钮（`.motion-paused`）会关闭它们，无 JS 时页面直接以静止状态呈现。

| 区域 | 变化 |
| --- | --- |
| 动效语汇 | `--ease-settle`（长减速，所有入场与切换）与 `--ease-soft`（轻微回弹，仅用于小控件） |
| 开场 | 标题两行依次上浮，随后眉题、侧栏、说明、主卡片与底栏逐步淡入；仅在 `<html>` 带 `intro` 类时运行（头部脚本按减少动态效果偏好添加） |
| 滚动 | Hero 文案随滚动轻微上移并淡出（CSS scroll-driven，合成器执行，不支持的浏览器保持静止）；下层只位移不淡出，避免卡片毛玻璃失效 |
| 入场 | 标题区、陈列台、笔记与 About 加入 `data-arrival`；同组兄弟元素自动错开 80 ms；位移 22 px，1.1 s 减速 |
| 实验缩略图 | FIG. 001 poster 缓慢漂移，悬停时轻微放大；FIG. 002 每条等高线错相起伏，形成向下传递的涟漪。仅在可见时运行 |
| 卡片 | `[data-surface]` 通用化：主卡片与兴趣卡片在指针下出现柔和光斑（四边羽化） |
| 主题切换 | View Transitions：新主题从切换按钮处以圆形展开；波浪直接跳到新配色，由展开本身充当过渡。不支持时退回颜色渐变 |
| 控件 | 暂停按钮改为胶囊形；主题按钮悬停轻转；滚动提示定时轻点 |
| 陈列台 | 切换展品时物件轻微缩放入场，说明与编号随之淡入 |

验证：`check-light-study.cjs` 通过；`check-lab.cjs` 除指针倾斜一段（无 GPU 环境帧过慢）外通过，该段已在绘制替换为空操作的条件下单独验证。开场、滚动、主题展开（动画降速 10 倍截取）与卡片光斑已截图复核。
